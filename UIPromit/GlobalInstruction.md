- Read and strictly follow `AGENTS.md` before starting.
- Build the required pages, sections, and reusable components according to Figma.

- Use only provided project/design icons. Never import or download external icons.
- If a required icon or asset is missing, do not invent or import one. Ask me first and wait for approval.

**Important – Frontend Only:**

You are not permitted to create any backend components on your own initiative. Work exclusively on the frontend; delete any backend code you have created that I did not explicitly request. Wait for my instructions before making any backend modifications, and do not touch any existing backend code.
